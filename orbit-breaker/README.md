# ORBIT BREAKER 3D

Трёхмерная космическая аркада STEP3D. Неоновые корабли, процедурная планета, волны захватчиков, боссы, усиления и оригинальный синтезируемый звук.

## Играть

https://step3dlab.github.io/SpaceInvader/orbit-breaker/

- A / D или стрелки — движение; Пробел — огонь.
- Q / Shift — ударный импульс с перезарядкой 20 секунд.
- Esc / P — пауза; M — звук.
- На телефоне — перемещение пальцем по сцене или экранные стрелки; автоматическая стрельба включена по умолчанию.
- Каждая пятая волна — босс. Усиления: тройной выстрел, ремонт, временный щит.
- Рекорды сохраняются локально отдельно для трёх уровней сложности.

## Запуск локально

```sh
python3 -m http.server 8000
```

Открыть http://localhost:8000. Сборка и npm не требуются. Для аппаратной графики нужен WebGL 2; при его отсутствии включается программная перспективная отрисовка той же 3D-сцены. После нажатия «Начать вылет» звук включается через Web Audio. Настройки позволяют отключить музыку, включить автоматический огонь, уменьшить качество и выключить тряску камеры.

## Файлы

- `core.mjs` — независимая игровая симуляция с фиксированным шагом времени.
- `scene.mjs` — настоящая 3D-сцена Three.js: объёмные модели, освещение, эффекты.
- `software.mjs` — резервный программный 3D-рендерер для устройств без WebGL.
- `audio.mjs` — процедурные звуки и музыка без сторонних аудиозаписей.
- `game.mjs` — интерфейс, управление, пауза, настройки, сохранение рекорда.
- `vendor/` — закреплённая Three.js 0.180.0, MIT. Работает без CDN.

Сцена, модели кораблей и аудио созданы программно. Нет аналитики, аккаунтов, платных API или удалённого хранилища. Игровые данные остаются в браузере.
